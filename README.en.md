Eventernote Autofill turns a public event page into reviewable and editable Eventernote event data. Start with one event URL, check every detail, and write to Eventernote only after final confirmation.

## Key features

- **Create event data from a URL**: Supports official websites, ticketing sites, X, Facebook, Instagram, and Eventernote pages, and can follow relevant ticket links found on the page.
- **Recognize multiple sessions**: When one source lists several dates or sessions, each event is separated for individual review.
- **AI-assisted verification**: Uses the event page, related links, and event images to help organize more complete information.
- **Review and edit every detail**: Update the event name, date, doors-open time, start and end times, venue, performers, description, and image.
- **Match Eventernote items**: Search for existing venues and performers, or explicitly confirm that a new item should be created.
- **Preview event images**: Use an image from the source, enter a public image URL, or upload a JPEG, PNG, or WebP image for review.
- **Confirm before writing**: A complete summary is shown before submission. Nothing is written to Eventernote until the user explicitly confirms it.
- **Three interface languages**: Switch between Traditional Chinese, Japanese, and English. The site remembers the selected language.

## How it works

1. Paste a public event URL and start the analysis.
2. Wait for the event information to be prepared. If the source contains multiple sessions, switch between them as needed.
3. Review and edit the event name, schedule, venue, performers, description, and image.
4. Search Eventernote for existing venues and performers, then choose an existing item or confirm a new one.
5. Review the final summary, return to editing if needed, or confirm the write.
6. Open the newly created Eventernote event page, or analyze another URL.

## Good to know

- Event descriptions are used only when they are provided directly by a source page. The field stays blank when no source description is available.
- Missing doors-open or end times may be inferred from the available schedule and are marked as low-confidence information that needs review.
- Edits and selected images remain only in the currently open browser page. Unfinished work is cleared when the page is reloaded or closed.
- The site never writes to Eventernote in the background. Every event requires final user confirmation.
