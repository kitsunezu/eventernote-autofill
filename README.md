<h1 align="center">Eventernote Autofill</h1>

<p align="center">
  <strong>繁體中文</strong> | <a href="README.en.md">English</a> | <a href="README.ja.md">日本語</a>
</p>

Eventernote Autofill 能將公開活動頁面整理成可檢查、可修正的 Eventernote 活動資料。從一個活動網址開始，確認所有內容後，才會寫入 Eventernote。

## 主要功能

- **從網址整理活動資料**：支援官方網站、售票網站、X、Facebook、Instagram 與 Eventernote 頁面，也會尋找頁面中相關的售票連結。
- **辨識多場活動**：同一來源包含多個日期或場次時，會拆成個別活動，方便逐場檢查。
- **AI 輔助核對**：參考活動頁面、相關連結與活動圖片，協助整理更完整的資料。
- **完整編輯與檢查**：可修改活動名稱、日期、開場與開始時間、結束時間、場地、演出者、活動介紹及圖片。
- **Eventernote 項目配對**：搜尋並選用現有場地與演出者，也可在確認後建立新項目。
- **活動圖片預覽**：可使用來源圖片、輸入公開圖片網址，或上傳 JPEG、PNG、WebP 圖片進行預覽。
- **逐步確認後送出**：送出前會顯示完整摘要；只有使用者明確確認後，才會寫入 Eventernote。
- **三語介面**：網頁可切換繁體中文、日文與英文，並記住目前選擇。

## 使用流程

1. 貼上公開活動網址並開始分析。
2. 等待網頁整理活動資訊；若來源包含多個場次，可在不同場次間切換。
3. 檢查並修改活動名稱、日期時間、場地、演出者、介紹與圖片。
4. 搜尋 Eventernote 的現有場地及演出者，確認要沿用現有項目或建立新項目。
5. 檢查最終摘要，返回修改或確認寫入。
6. 完成後可直接開啟建立好的 Eventernote 活動頁面，或分析另一個網址。

## 使用時需注意

- 活動介紹只會採用來源頁面直接提供的內容；若來源沒有介紹，欄位會保持空白。
- 缺少的開場或結束時間可能會依現有時間推算，並標示為需要確認的低可信度資料。
- 編輯中的內容與所選圖片只保留在目前開啟的瀏覽器頁面。重新整理或關閉頁面後，未完成的內容不會保留。
- 網頁不會在背景自動寫入 Eventernote；每筆活動都需要使用者完成最終確認。
