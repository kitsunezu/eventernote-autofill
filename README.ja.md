<h1 align="center">Eventernote Autofill</h1>

<p align="center">
  <a href="README.md">繁體中文</a> | <a href="README.en.md">English</a> | <strong>日本語</strong>
</p>

Eventernote Autofill は、公開されているイベントページから、確認・修正できる Eventernote 用のイベント情報を作成します。1件のイベント URL を入力し、すべての内容を確認した後にのみ Eventernote へ登録します。

## 主な機能

- **URL からイベント情報を整理**：公式サイト、チケットサイト、X、Facebook、Instagram、Eventernote のページに対応し、ページ内の関連するチケットリンクも確認します。
- **複数公演を個別に認識**：1つのページに複数の日程や公演がある場合、それぞれを個別のイベントとして確認できます。
- **AI による確認支援**：イベントページ、関連リンク、イベント画像を参照し、より完全な情報へ整理します。
- **すべての項目を確認・編集**：イベント名、日付、開場・開演・終演時刻、会場、出演者、説明、画像を編集できます。
- **Eventernote 項目との照合**：既存の会場・出演者を検索して選択できます。新規項目を作成する場合も、明示的な確認が必要です。
- **イベント画像のプレビュー**：取得した画像、公開画像の URL、またはアップロードした JPEG・PNG・WebP 画像を確認できます。
- **登録前の最終確認**：送信前に全項目の概要を表示し、利用者が明示的に確認した場合にのみ Eventernote へ登録します。
- **3言語の表示**：繁体字中国語、日本語、英語を切り替えられ、選択した言語は保存されます。

## 使い方

1. 公開イベントの URL を貼り付け、解析を開始します。
2. イベント情報の整理が完了するまで待ちます。複数公演がある場合は、公演ごとに切り替えて確認します。
3. イベント名、日時、会場、出演者、説明、画像を確認・修正します。
4. Eventernote で既存の会場・出演者を検索し、既存項目を使用するか、新規作成するかを確認します。
5. 最終確認画面で概要を確認し、必要なら編集に戻るか、登録を確定します。
6. 作成された Eventernote のイベントページを開くか、別の URL を解析します。

## ご利用上の注意

- イベント説明は、参照元ページに直接掲載されている場合のみ使用します。説明がない場合、入力欄は空欄のままです。
- 開場または終演時刻がない場合、取得済みの時刻から推測されることがあります。推測値は確認が必要な低信頼度の情報として表示されます。
- 編集中の内容と選択した画像は、現在開いているブラウザページ内にのみ保持されます。ページを再読み込みまたは閉じると、未完了の内容は失われます。
- バックグラウンドで Eventernote に自動登録されることはありません。イベントごとに利用者の最終確認が必要です。
